**Pillxa** 是一套面向日常用药场景的智能药盒系统。

---

## 目录结构

```text
Pillxa/
├── backend/            # 后端服务
├── app/                # 用户客户端
├── firmware/           # 硬件固件
├── AGENTS.md           # Agent 协作规范
└── README.md           # 项目说明文档
```

### 主要模块说明

- **`backend/`**：基于 FastAPI 的后端服务。
- **`app/`**：用户客户端。
- **`firmware/`**：智能药盒硬件固件。
