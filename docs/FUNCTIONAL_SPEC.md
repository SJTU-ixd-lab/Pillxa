# 排药模块功能说明

## 1. 模块目标

让照护者在不容易漏放、错放和重复放药的前提下，为固定 4 × 7 格子板准备一个用药周期，并把计划以模拟 NFC 流程写入格子板。

目标用户为李秀兰的女儿李雯。界面以「一次只做一件事」「当前格子明显高亮」「任何关键结果都要人工确认」为原则。

## 2. 页面与状态

| 页面 | 主要状态 | 核心操作 |
| --- | --- | --- |
| 排药首页 | 使用中、空置、排药中、待启用 | 选择格子板、继续排药 |
| 确认计划 | 正常、药品停用、无启用药品 | 识别处方、手动添加、确认计划 |
| 识别处方 | 待拍照、识别中 | 模拟拍照并识别 |
| 核对结果 | 未确认、部分确认、全部确认 | 核对识别药品并保存 |
| 布局预览 | 1/2/3-4 个服药时段 | 查看覆盖天数、确认准备动作 |
| 逐一排药 | 第 N 种药、保存退出 | 按高亮格放药、切换药品 |
| 拍照验药 | 待拍照、检查中、通过 | 拍照检查、重新拍摄 |
| NFC 写入 | 等待、写入中、成功、失败 | 写入、查看失败、重试 |
| 完成摘要 | 待启用 | 返回首页、分享摘要模拟 |

## 3. 固定格子板规则

- 格子板总数：2 块。
- 每块板：4 行 × 7 列，共 28 格。
- 当前演示计划有早餐后、午餐后、晚餐后三个时段，因此覆盖 7 天。
- 前三行分别对应早餐后、午餐后和晚餐后。
- 第四行为备用行，当前周期保持为空。
- 若只有 1 个每日时段，理论覆盖 28 天；若有 2 个时段，理论覆盖 14 天；3-4 个时段覆盖 7 天。

## 4. 演示数据

使用《药盒 APP beta》中的统一画像：

- 用药者：李秀兰，65 岁。
- 照护者：女儿李雯。
- 药品：苯磺酸氨氯地平片、二甲双胍缓释片、阿托伐他汀钙片、碳酸钙 D3 片、骨化三醇胶丸。

## 5. 安全交互

- 处方识别结果必须逐项确认后才能保存。
- 识别页面声明功能不判断处方合理性。
- 逐一排药页同时显示每格数量和本步总数量。
- 排药中途退出时明确说明进度会保留。
- NFC 写入中禁止返回，避免产生不明确状态。
- 写入成功后格子板改为「待启用」，不会直接替换正在使用的格子板。

## 6. 前端模拟范围

以下交互以延时和页面状态模拟：

- 相机拍摄和处方识别；
- 格子板照片检查；
- NFC 发现、写入、成功、失败和重试；
- 分享排药摘要。

这些模拟点已经集中在对应页面中，后续接入真实能力时可以替换调用逻辑而保留界面结构。
