# Pillxa Firmware Module (智能药盒硬件固件)

本目录为 **Pillxa 智能药盒系统** 的硬件嵌入式微控制器程序（固件）预留源码目录。

## 🎯 模块定位与职责

- **出药执行与仓位控制**：驱动电机与机械结构，在指定时段将药品精准推送至取药口。
- **传感器数据采集**：检测药盒开盖状态、余药红外感应以及取药动作确认。
- **设备声光交互**：控制 LED 指示灯闪烁与蜂鸣器/语音提示，引导用户取药。
- **网络与配网通信**：支持 Wi-Fi / BLE 通信，从云端后端拉取用药计划并上报服药确认事件。
