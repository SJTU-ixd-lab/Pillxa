# Pillxa App Module (客户端/移动端应用)

本目录为 **Pillxa 智能药盒系统** 的用户客户端（移动端 App / 小程序 / Web 应用）预留源码目录。

## 🎯 模块定位与职责

- **用户用药计划管理**：提供可视化界面，供用户或家属设定、调整每日用药计划与频次。
- **服药提醒与推送**：接收云端推送，并在用药时段提醒用户服药。
- **药盒设备协同**：支持通过蓝牙（BLE）或 Wi-Fi 进行硬件药盒配网、绑定与实时状态同步。
- **健康数据统计**：统计用户的服药遵从率与历史服药记录。
